# Enicar Archive

An independent, sourced index of vintage Enicar watches. Static site, data in
YAML, every fact cited. Managed by Claude; see [CLAUDE.md](CLAUDE.md).

```bash
npm install
npm run dev        # local site at http://localhost:4321 (no search)
npm run check      # the full QA gate
npm run build && npx astro preview   # built site, with search
```
